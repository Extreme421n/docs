<Note>
**Recommended for new integrations.** Proxy mode is the fastest path
to observability, and it's the only mode that supports zero
application code changes.
</Note>

## How it works

```
   your app  ──►  api.prompt-wall.com/v1/chat/completions
                                      │
                                      ├─ pre-LLM   (optional)
                                      ▼
                                 OpenAI / Azure / Together
                                      │
                                      ├─ post-LLM  (optional)
                                      ▼
                                  back to your app

   ↳ every request becomes a row on the Observability dashboard
```

PromptWall:

1. Authenticates your `X-PromptWall-Api-Key` (returns 401 immediately
   if invalid — no charge to your OpenAI account)
2. Optionally runs **pre-LLM** control: guard injection + injection scan
3. Forwards your request **byte-identical** to the upstream provider
   with your OpenAI key in the `Authorization` header
4. Optionally runs **post-LLM** control: PII redaction, future output policies
5. Emits a canonical Trace row and returns the upstream response

## Setup

You change **two things** on the customer side:

1. `OPENAI_BASE_URL` → `https://api.prompt-wall.com/v1`
2. Add an `X-PromptWall-Api-Key` default header

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.prompt-wall.com/v1",
    api_key=os.environ["OPENAI_API_KEY"],
    default_headers={
        "X-PromptWall-Api-Key": os.environ["PROMPTWALL_API_KEY"],
        # Optional dimensions — sliceable in Observability:
        "X-Use-Case":           "customer_support",
        "X-Team-Id":            "support-eu",
        "X-Integration-Id":     "support-bot-prod",
        "X-End-User-Id":        "user-pseudonym",
        "X-Session-Id":         "conversation-id",
        # Optional control mode:
        # "X-PromptWall-Mode":  "full",
    },
)
```

```javascript Node.js
import OpenAI from "openai";

const openai = new OpenAI({
  baseURL: "https://api.prompt-wall.com/v1",
  apiKey:  process.env.OPENAI_API_KEY,
  defaultHeaders: {
    "X-PromptWall-Api-Key": process.env.PROMPTWALL_API_KEY,
    "X-Use-Case":           "customer_support",
    "X-Team-Id":            "support-eu",
    "X-Integration-Id":     "support-bot-prod",
    // "X-PromptWall-Mode": "full",
  },
});
```

```bash cURL
curl https://api.prompt-wall.com/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "X-PromptWall-Api-Key: $PROMPTWALL_API_KEY" \
  -H "X-Use-Case: customer_support" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role":"user","content":"Hello"}]
  }'
```

</CodeGroup>

Streaming (`"stream": true`) works without any extra setup; the proxy
forwards SSE chunks byte-by-byte.

## Control modes

Default is **observe** — capture only, no mutations. To turn on
control, send `X-PromptWall-Mode` per request or set
`policy_json.proxy_control_mode` per tenant.

| Mode      | Pre-LLM              | Post-LLM         | Streaming behaviour |
|-----------|----------------------|------------------|---------------------|
| `observe` | ✗                    | ✗                | unchanged           |
| `guard`   | guards + input scan  | ✗                | unchanged           |
| `verify`  | ✗                    | PII redaction    | downgrades to observe |
| `full`    | both                 | both             | downgrades to guard for streams |

The effective mode is reflected back as `X-PromptWall-Mode` in the
response headers, so your app can verify what ran.

## Headers reference

| Request header             | Required | Purpose                                         |
|----------------------------|----------|-------------------------------------------------|
| `Authorization: Bearer …`  | yes      | Your OpenAI key — forwarded to upstream         |
| `X-PromptWall-Api-Key`     | yes      | Your PromptWall key — tenant attribution        |
| `X-Use-Case`               | no       | Dashboard dimension; defaults to `default`      |
| `X-Team-Id`                | no       | Dashboard dimension                             |
| `X-Integration-Id`         | no       | Dashboard dimension; defaults to `proxy:openai` |
| `X-End-User-Id`            | no       | End-user pseudonym (not raw PII)                |
| `X-Session-Id`             | no       | Multi-turn session correlation                  |
| `X-PromptWall-Mode`        | no       | Override tenant control mode for this request   |

| Response header               | Meaning                                       |
|-------------------------------|-----------------------------------------------|
| `X-PromptWall-Request-Id`     | Trace ID for correlation in the dashboard     |
| `X-PromptWall-Mode`           | Effective control mode after stream-downgrade |
