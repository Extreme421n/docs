Base URL: `https://api.prompt-wall.com`

All endpoints require authentication. See [Authentication](/api-reference/authentication).

## Versioning

Current version: `v1`. Breaking changes will be introduced as `v2`, `v3`, etc.

## Rate limits

- Default: **120 requests/min** per API key
- Strict endpoints (policy mutations): **30/min**

Exceeded limits return `429` with `Retry-After` header.

## Response format

Success responses have `"ok": true`. Error responses have `"ok": false`
with an `error` object:

```json
{
  "ok": false,
  "error": {
    "code": "QUOTA_EXCEEDED",
    "message": "Plan quota exceeded (10001/10000)",
    "plan_id": "byok_starter"
  }
}
```
